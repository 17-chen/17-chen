# Hi, I'm Willings Chen 👋

I'm based in Wenzhou and interested in **applied AI, knowledge tools, and software that makes learning easier**. I like starting with a problem people actually face, building a working prototype, and improving it as I understand the problem better.

Several questions keep drawing me back: How can saved information become knowledge we use? How can an AI tool stay clear and dependable when a task is difficult? And how can the process of building software become a learning resource in its own right? The projects below are my ways of exploring those questions.

## Selected work

### VideoMind AI

I save videos because I want to learn from them, but a growing watch-later list is easy to forget. VideoMind AI explores a more useful path: turn a video into a structured note, keep it in a personal knowledge base, and make its contents searchable and open to questions. The current project brings together video processing, subtitles or transcription, AI analysis, and retrieval-based chat.

[Explore VideoMind AI](https://github.com/17-chen/videomind-ai)

### FirstAid Copilot

In an emergency, instructions need to be clear, timely, and easy to follow. FirstAid Copilot is a local-first prototype for guiding a bystander through adult CPR. Its design keeps the core guidance in a rule-based state machine while using an on-device model for conversation; the project also explores offline voice interaction, safety checks, and a structured handover for responders.

[Explore FirstAid Copilot](https://github.com/17-chen/first-aid-co-pilot)

### Project Mentor

AI can help someone produce code quickly, but that does not always mean they understand the system they have built. Project Mentor is a Codex skill that reads a project, a development conversation, or both, and turns the evidence into a beginner-friendly software engineering course in Chinese. It explains architecture, workflows, decisions, risks, and next steps so the work can be learned from, not merely repeated.

[Explore Project Mentor](https://github.com/17-chen/project-mentor)

### Portfolio Project Manager

Long-running projects need more than a list of files. This Codex skill helps preserve project context across sessions: goals, architecture, decisions, tasks, changes, and handoff notes. I built it to make it easier to return to a repository, understand its current state, and continue with a clearer sense of what matters next.

[Explore Portfolio Project Manager](https://github.com/17-chen/portfolio-project-manager)

## What I'm exploring now

- AI tools that help people turn information into understanding and action.
- Clearer boundaries and more dependable behavior in AI-assisted workflows.
- Bilingual learning tools that help beginners understand code and technical ideas.

You can find more experiments in my [repositories](https://github.com/17-chen?tab=repositories), including a [bilingual Java tutoring skill](https://github.com/17-chen/java-beginner-tutor). I'm always glad to exchange ideas or learn from people working on related problems.

# 你好，我是 Willings Chen 👋

我目前在温州，关注 **AI 的实际应用、知识工具，以及能让学习变得更清楚的软件**。我喜欢从真实问题出发，先做出可运行的原型，再随着理解的深入不断改进。

有几个问题一直吸引我：收藏的信息怎样才能真正变成自己的知识？在复杂甚至紧张的情境中，AI 工具怎样给出清楚、可靠的帮助？借助 AI 开发软件的过程，又怎样沉淀为初学者也能读懂的学习材料？下面这些项目，是我对这些问题的探索。

## 代表项目

### VideoMind AI

很多视频被加入“稍后观看”，却很容易留在收藏夹里。VideoMind AI 尝试把视频转换成结构化笔记，存入个人知识库，让内容可以被搜索、回顾和提问。目前的项目串联了视频处理、字幕获取或转写、AI 分析，以及基于检索的视频问答。

[查看 VideoMind AI](https://github.com/17-chen/videomind-ai)

### FirstAid Copilot

紧急时刻，指引需要清楚、及时，也要让普通人能够跟上。FirstAid Copilot 是一个面向成人心肺复苏场景的端侧原型：核心急救流程由规则状态机控制，设备端模型负责自然语言交互。项目还探索了离线语音、安全校验和供急救人员接手时使用的结构化交接信息。

[查看 FirstAid Copilot](https://github.com/17-chen/first-aid-co-pilot)

### Project Mentor · AI 工程导师

AI 可以帮助我们更快写出代码，但完成项目不等于真正理解了它。Project Mentor 是一个 Codex Skill，能够结合项目代码、开发对话或两者的信息，整理出适合初学者阅读的中文软件工程课程。它解释架构、开发流程、技术决策、风险与下一步，让项目不仅能继续做，也能成为学习材料。

[查看 Project Mentor](https://github.com/17-chen/project-mentor)

### Portfolio Project Manager

长期项目需要的不只是一组文件，还需要可追溯的上下文。这个 Codex Skill 用结构化文档记录项目目标、架构、决策、任务、变更和交接信息。我做它是为了在隔了一段时间后回到仓库时，仍能快速看清项目现在在哪里，以及接下来该做什么。

[查看 Portfolio Project Manager](https://github.com/17-chen/portfolio-project-manager)

## 现在关注的方向

- 让 AI 帮人们把信息转化为理解和行动。
- 为 AI 辅助工作流建立更清晰的边界和更可靠的行为。
- 制作帮助初学者理解代码与技术概念的双语学习工具。

你也可以在我的[其他仓库](https://github.com/17-chen?tab=repositories)中看到更多尝试，包括一个[双语 Java 入门辅导 Skill](https://github.com/17-chen/java-beginner-tutor)。欢迎交流想法，也欢迎分享你正在解决的问题。
